# Projeto EBOOK sobre Futebol Gerado por I.A.s para o Santander Bootcamp DIO

> ℹ️ **NOTE:** Este é o repositório com o projeto desenvolvido para o Santander Bootcamp na plataforma da [DIO](https://dio.me).

Projeto com o objetivo de gerar um ebook digital sobre futebol com as facilidades das ferramentas de IA. Todos os prompts
seguem abaixo.

## 💻 Tecnologias utilizadas no projeto

- [ChatGPT](https://chat.openai.com/) 
- [MidJourney](https://www.midjourney.com/app/)
- [PowerPoint](https://www.microsoft.com/en/microsoft-365/powerpoint)

## 🧠 Prompts


ChatGPT：

|   Ação   | prompt                                                                                                                                                                                                                                                                         |
| :------: | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
|  título  | Crie um título de um ebook sobre o tema de futebol, o ebook é do nicho de esportes e o subnicho é de táticas de futebol, o título deve ser épico e curto, e tenha uma temática de 'lenda do futebol' no título, me liste 5 variações de títulos                                   |
| conteúdo | Faça um texto para ebook, com foco em táticas de futebol, listando as principais formações táticas com exemplos. {REGRAS} Explique sempre de uma maneira simples. Deixe o texto enxuto. Sempre traga exemplos de uso em contextos reais de times famosos. Sempre deixe um título sugestivo por tópico |


Midjourney：

|  Ação  | prompt                                                                                 |
| :----: | -------------------------------------------------------------------------------------- |
| título | A legendary soccer player celebrating a goal in a stadium, with the crowd blurred in the background, dramatic lighting, digital art style --v 5.1 |

## ✨ Features

- Conteúdo sobre futebol gerado via ChatGPT
- Imagens de futebol geradas via MidJourney

## 📚 Materiais

- Imagens utilizadas em `assets`
- ebook gerado durante as aulas em `output`

## 🛠️ Instruções de execução

Utilize os prompts acima nas ferramentas sugeridas para gerar o material base e utilize uma ferramenta de edição de documentos como power point, libreoffice , indesign para diagramação.
